## 2. Patterns worth learning from (strategy, not copying)

1. **Prices in titles and snippets.** Operators show "from ₹X" in titles. HCC's titles already carry the price where it fits within 65 characters (`seo.ts`); keep that.
2. **"How to reach" posts rank for operators.** HCC should put this information in existing destination guides, not in new posts.
3. **Comparison posts.** Travloger's "Coorg or Ooty?" shows the format ranks. HCC's three-way comparison draft is noindex, pending review.
4. **Coverage beats depth only on low-competition queries.** HCC can't match Weekend Yaari's page count and shouldn't try (no mass content rule). Win the ~15 queries that matter with better pages.

## 3. HCC's real differentiators (use only what's true)

- A fixed Thu/Fri departure model from Hyderabad with overnight trains, so a weekend works with 1–2 leave days. Confirmed in trip data.
- One clear price per person with Included/Extra lists (single-price model).
- A camping heritage ("Campers Club"); EST. 2020 per the owner-supplied logo.
- Genuine Google reviews (the owner confirmed these exist). Link to them; **never** copy or rewrite them.

**Don't claim:** "best", "No. 1", "largest", traveller counts, or safety records, unless HCC supplies evidence.

## 4. Monitoring

Monthly, manually check the SERP for the P0 keywords (`keyword-universe.json`) and note new entrants and price changes in `monthly-report-template.md` §8. Once Search Console is connected, use the query report rather than guessing.
